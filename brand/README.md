## Locked decisions (founder, 2026-11-17)

- Brand name **TUCKER**; wordmark direction **tucker.**
- Business: a home-service savings brokerage. Descriptor: **Your home service savings broker.**
- Core concept: simple savings on everyday household services. Promise: *we compare, we help, you choose.*
- Mascot: a **brown bear**, the Working Bear, in a trucker-inspired cap and clean workwear. No human trucker, no other species.
- Campaign line (experimental, selected advertising only): **One money-saving mother trucker.**
- TUCKER is not a trucking company and never claims guaranteed savings.

## Proposed (awaiting Gate G1)

- Creative territory: **C · Name Patch** (Balanced Working Bear), produced flat-master-first. See the territories doc.
- Ownable devices: the stitched name patch as the logo lockup; the period as Tucker's nose.
- Mascot guardrails (distance from existing characters): see territories doc §2.

## Rejected directions

- Human trucker mascot; any non-bear species (directive §14).
- Red cap, yellow circular badge, frontal toothy grin (too close to an existing, actively litigated convenience-store mascot).
- Campaign hat, shovel, shirtless-with-jeans look (too close to a government-owned bear character).
- Script lettering in an oval patch (reads as an automotive marque).
